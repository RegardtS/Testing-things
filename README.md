# Hello World — Vue.js

A minimal [Vue 3](https://vuejs.org/) + [Vite](https://vitejs.dev/) app used for
testing, deployed on [Vercel](https://vercel.com/).

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # build for production into dist/
npm run preview  # preview the production build
```

## Deploying to Vercel

Vercel auto-detects the Vite framework preset — no extra configuration needed:

- **Build command:** `npm run build`
- **Output directory:** `dist`

Every push to the connected branch triggers a new deployment.
